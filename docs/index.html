MySQL、MariaDB 與 Redis，
一個安靜好用的桌面工具。

MyDB Studio 用 Rust + Tauri 2 打造，連線、查詢、管理伺服器都在同一個視窗；AI 只跑在你自己的電腦上，也能透過 MCP 讓 Claude 等工具安全地使用你存好的連線。

功能

日常查詢到伺服器管理，常用的事情都放在順手的位置。

連線

  • SSL/TLS 四種模式，對應 mysql 的 --ssl-mode
  • 雲端預設：AWS RDS / Aurora、Google Cloud SQL、Azure；Redis 有 ElastiCache / MemoryDB、Memorystore
  • SSH 通道，第一次連線記住跳板機金鑰指紋，之後不符就拒絕
  • 閒置斷線後自動重連（含 SSH 通道），保留 USE 的資料庫

SQL 編輯器

  • 多分頁，釘選的分頁下次開同一連線時還原
  • 自動完成資料庫、資料表、欄位名稱
  • 只執行選取或游標所在那句；Explain 標出全表掃描
  • Snippet 縮寫展開，${欄位} 用 Tab 依序填
  • 「■ 停止」中止查詢；「匯出全部」串流寫進檔案

結果表格

  • 選取儲存格、整列或整欄複製
  • 存成 TSV、CSV、JSON、INSERT SQL、Markdown
  • CSV 有試算表公式防護：以 =、+、-、@ 開頭的文字會先加上 '

執行紀錄與報表

  • 記錄每次執行的 SQL、耗時、影響／回傳筆數、錯誤與結果預覽
  • 可搜尋、篩選、加備註，帶回編輯器
  • 勾選紀錄產生 Markdown、HTML 或 CSV 報表

結構管理

  • 建立、刪除資料庫，修改字元集與定序，可一併 CONVERT 所有資料表
  • 資料表設計器：欄位、索引、外鍵一起改，合併成一句 ALTER TABLE 先預覽
  • 檢視、預存程序、函式、觸發器、事件直接編輯；MySQL 重建失敗會自動還原
  • 刪除要輸入名稱確認；每次變更都存進執行紀錄，附上變更前的定義

伺服器管理

  • 版本、運行時間、連線數、快取命中率等重要指標
  • 狀態與系統變數搜尋；執行中的查詢可以中止
  • 使用者新增、改密碼、鎖定、刪除
  • 權限勾選與預設組合，套用前先預覽 GRANT／REVOKE

Redis

  • 只用 SCAN 分批載入 key，依冒號前綴分組
  • 依型別檢視值，大型集合分頁
  • 指令列一行一個指令；KEYS、FLUSHALL 等危險指令先確認
  • 指令寫進執行紀錄，AUTH 的密碼一律遮蔽

本機 AI

  • 用 llama.cpp 在本機執行 Qwen2.5-Coder（7B 建議，3B 省記憶體）
  • 分析錯誤、解釋 SQL、給出修改建議
  • 不用的時候模型不會啟動，閒置後自動停止

MCP server

  • mydb-studio --mcp 讓 Claude 等 AI 工具用存好的 MySQL / MariaDB 連線查詢
  • 每個連線可設定關閉、唯讀（預設）或可寫入
  • AI 執行的查詢都會寫進執行紀錄並加上備註

App 鎖定

  • 用 Touch ID 或登入密碼解鎖
  • 閒置一段時間、螢幕鎖定或睡眠時自動鎖定
  • 可設定開啟 app 時就先鎖定、鎖定時關閉連線

安全與隱私

資料庫裡的東西很重要，所以預設值都往保守的方向走。

AI 在本機執行

預設由 app 在本機啟動 llama.cpp 的 llama-server，只聽 127.0.0.1，資料不會送到雲端服務。若你已經自己架好 llama.cpp 伺服器，也可以在設定裡改用它。

密碼放在 macOS 鑰匙圈

連線密碼、SSH 密碼與金鑰密語存在系統鑰匙圈，app 資料庫只保存不含密碼的連線設定。密碼也只會交給原本設定的主機。

MCP 預設唯讀

唯讀連線只接受 SELECT、SHOW、DESCRIBE、EXPLAIN，並在唯讀交易中執行作為第二道防線。要開放寫入必須逐一連線手動設定；Redis 連線不提供給 MCP。

App 鎖定也鎖住 MCP

App 鎖定時，MCP server 會拒絕所有工具呼叫，直到你用 Touch ID 或登入密碼解鎖；即使 app 異常結束，也會依設定保持鎖定。

技術棧

核心邏輯與 UI 分開，桌面 app 和 MCP server 共用同一套程式碼。

核心

Rust：連線、SSH 通道、查詢、SQL 分句、本機 SQLite（crates/mydb-core）

桌面殼層

Tauri 2，把核心包成前端可呼叫的指令（src-tauri）

前端

React + TypeScript，CodeMirror 編輯器（src）

AI 與整合

llama.cpp 本機模型；MCP（JSON-RPC over stdio，crates/mydb-mcp）

下載與安裝

macOS 版已經用 Developer ID 簽章並通過 Apple 公證。

安裝：到 GitHub Releases 下載 zip，解壓後把 MyDB Studio.app 拖進「應用程式」。目前提供 Apple Silicon（M 系列晶片）版本；Intel Mac 可以從原始碼建置。

從原始碼建置

  1. 安裝 Rust（stable）與 Node 22
  2. 依照 Tauri 文件安裝系統套件
  3. 取得原始碼，安裝相依套件後執行
# 取得原始碼
$ git clone https://github.com/jackiewu/mydb-studio.git
$ cd mydb-studio

# 安裝相依套件
$ npm install

# 開發模式
$ npm run tauri dev

# 打包安裝檔
$ npm run tauri build

# 測試
$ cargo test --workspace
$ npm test
